# A heartbeat check before showing the output (follow-up 1)

Numbers: `results/gate/summary.md` (generated by `scripts/gate.py`), figure `results/gate/scores.png`.

Phase 5 found that every model draws a convincing ECG from noise. This tests two simple checks on 8 s
windows of the SCG:

- **Periodicity:** the highest autocorrelation peak of the SCG's 5-30 Hz energy envelope at a heart-rate
  lag (0.4-1.5 s). A heartbeat repeats; noise does not.
- **Seed agreement:** the mean pairwise correlation of three U-Nets trained with different seeds.

Thresholds are set per fold on the 2 tune people, so that 95% of their real windows pass. The tune
people are neither trained on nor tested on. The checks are then scored on the 4 unseen test people of
each fold. Negatives are built at the same scale: white, pink and brown noise, and the person's own SCG
cut into 50 or 200 ms blocks and shuffled.

## Fraction of 8 s windows that pass (16 people)

| input | periodicity | seed agreement |
|---|---|---|
| real SCG | **0.92** | 0.73 |
| real SCG, sign flipped | 0.90 | 0.84 |
| white / pink / brown noise | **0.00** | 0.00 |
| SCG shuffled in 50 ms blocks | **0.004** | 0.41 |
| SCG shuffled in 200 ms blocks | **0.004** | 0.58 |

- **Periodicity is the heartbeat check.** It needs no ECG, no model and no calibration. Real windows pass
  92% of the time (the target was 95%), and noise or scrambled SCG almost never does. It is indifferent
  to the sensor's sign, as it should be.
- **Its weak spot is an irregular heart.** Subject 18, whose rhythm is the least regular (6% irregular
  beats), passes only 64% of real windows; subject 5 passes 72%. A periodicity check will
  withhold output more often for people with arrhythmias, which are the people a clinician most wants
  to see. In a real device a rejected window should read "no reliable signal", not "no heartbeat".
- **Seed agreement is not a heartbeat check.** It passes 41-58% of scrambled SCG, and its threshold
  swings between folds (0.47-0.88).
- **Seed agreement is a rough quality flag.** On real windows it tracks how good the output is
  (Spearman 0.39). Windows it rejects have a median output r of 0.55, against 0.81 for those it keeps. It
  mostly rejects whole people: subjects 1, 2, 5 and 18, most of them among the U-Net's worst. Periodicity
  barely tracks output quality (0.13), which is expected: it asks whether there is a heartbeat, not
  whether the model will draw it well.

## Recommendation

Use the periodicity check as a gate: no output for windows that fail it. Report seed agreement next to
the output as a confidence score. Neither check can tell whether the drawn beat shape is right for this
person. Only calibration (`docs/05_calibration.md`) addresses that.
